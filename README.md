# Paper-Scissors-Game

Who didn't play this game when they were young? Even now, a lot of us still play it with our friends just for fun. That's why I decided to make my own version and challenge the computer instead. It's a simple and funny game that brings back some good memories while also being a nice coding project.

# What I Learned

This project helped me learn how to use the Tkinter library to create graphical user interfaces in Python. I also got a better understanding of the game logic and how to connect it with a GUI. Before creating the graphical version, I first made a CLI (Command Line Interface) version in my first commit to focus on the game mechanics. After that, I improved it by adding a user-friendly interface, which made the project much more enjoyable to use.

Overall, this was a really fun project and a great way to practice both Python programming and GUI development.

# How to Run

Go to the Releases section and download the `.exe` file, then run it and start playing against the computer.
